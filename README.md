# ☁️ AWS Infrastructure Diagram Design Exercises

This repository contains my hands-on exercises and labs for learning how to **design AWS infrastructure architecture diagrams**.

The goal of this repository is to practice planning, designing, and visually representing AWS cloud infrastructures before implementing them.

These exercises focus on understanding **how AWS services connect and work together** to build secure, scalable, highly available, and well-structured cloud architectures.

---

## 🛠️ Diagram Tools

Architecture diagrams may be created using tools such as:

* Draw.io / diagrams.net
* Lucidchart
* Microsoft Visio
* AWS Architecture Icons

Whenever possible, diagrams should use the official AWS architecture icons so that AWS resources can be identified easily.
